# YoTrack Claude Instructions

`AGENTS.md` is the canonical instruction file for every coding agent working on YoTrack.

Before working:

1. Read and follow `AGENTS.md`.
2. Use `docs/CONTEXT_MAP.md` to load only the context relevant to the current task.
3. Do not duplicate rules in this file; update `AGENTS.md` when a cross-agent rule changes.

For the active production verification handoff (Scheduled Reports, Device Health, and Gateway CRC), read `docs/CLAUDE_HANDOFF.md`.
